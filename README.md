# Zahra

A restaurant website mockup for Zahra, a Lebanese kitchen and shisha lounge. The site includes the menu, reservations, waitlist, banquet enquiries, and online ordering.

## Run locally

**Prerequisite:** Node.js

1. Install dependencies:
   `npm install`
2. Start the site:
   `npm run dev`

## GitHub Pages

Pushes to `main` run `.github/workflows/pages.yml`, which builds the site and deploys it.

In the repository settings, open **Pages** and set the source to **GitHub Actions**. The workflow prints the published URL when it finishes.
